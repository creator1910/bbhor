# $JOB

> Trade your job like an asset.

$JOB prices your career using public company signals, role economics, and AI analysis.
Enter a company and role — get a synthetic stock ticker, a BUY/HOLD/SELL/SHORT rating, and an analyst memo in seconds.

---

## What it does

1. User enters **company**, **role**, and **risk appetite**.
2. Backend queries **Tavily** for live company signals (news, hiring, momentum).
3. Signals are sent to **Gemini** which produces a structured financial-style analysis.
4. Frontend renders the result as a Bloomberg-style dashboard: ticker card, chart, scores, bull/bear cases, and alternatives.

---

## Demo flow

```
Landing → Input form → Loading scan (cinematic) → Dashboard result
```

The dashboard shows:
- Synthetic ticker (e.g. `N26-PM`)
- Rating card: BUY / HOLD / SELL / SHORT
- 12-month synthetic price chart
- Momentum / Salary Yield / Volatility / Upside scores
- Analyst memo (bull case, bear case, recommendation)
- Alternative paths (stay / competitor / independent)
- Source cards from Tavily

## Setup

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# Add your TAVILY_API_KEY and GOOGLE_API_KEY to .env

uvicorn backend.main:app --reload --port 8000
```

The API is now available at `http://localhost:8000`.

### Frontend

See Ole's branch `frontend-workfolio`. Set the backend URL in the frontend env:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## API documentation

### `POST /api/analyze-job-stock`

**Request body:**

```json
{
  "company": "N26",
  "role": "Product Manager",
  "riskAppetite": "balanced"
}
```

`riskAppetite` must be one of: `safe` | `balanced` | `ambitious` | `founder`

**Response:** see [`docs/api-contract.md`](docs/api-contract.md) for the full schema.

**Example curl:**

```bash
curl -X POST http://localhost:8000/api/analyze-job-stock \
  -H "Content-Type: application/json" \
  -d '{"company":"N26","role":"Product Manager","riskAppetite":"balanced"}'
```

## Architecture

```
Frontend (Lovable / Next.js)
        │
        │  POST /api/analyze-job-stock
        ▼
FastAPI (backend/main.py)
        │
        ├── Tavily (3 parallel queries)
        │     ├── Company overview
        │     ├── Recent news
        │     └── Hiring signals
        │
        ├── Gemini 2.0 Flash (structured JSON output)
        │
        └── Fallback (curated mock — always safe)
```

---

## How Tavily is used

Three parallel searches run against the company name:
1. `{company} overview business model funding` — general context
2. `{company} latest news layoffs growth product` — sentiment signals
3. `{company} hiring {role} jobs careers` — hiring momentum

Results are summarized and injected into the Gemini prompt as free-text signals.

---

## How AI scoring works

Gemini receives a structured prompt with:
- Company and role
- User risk appetite
- Tavily research signals

It returns strict JSON (enforced via `response_mime_type: application/json`) with scores (0–100), a rating, bull/bear cases, and alternatives. Scores are clamped and validated before being returned to the frontend.

---

## Known limitations

- Chart data is synthetic (generated by LLM) — not real stock prices.
- Scores are AI estimates, not verified financial metrics.
- Tavily results vary by company size — niche companies get fewer signals.
- No auth, no persistence, no user accounts — pure demo.
